## A. 보스 온그리드 엔티티 (요청 ①+② 통합 해결)

지금 보스는 **그림일 뿐**(보드 상단 장식, 공격은 전부 0행 웨이브). 보스를 실제 셀에 올린다.

### A1. 엔티티화
- `s.bossPos { r, c }` — 보스가 상단 1~3행의 셀을 실제 점유. 아바타 렌더 = 보스 셀 위치(겹침 해소).
- 보스 셀 진입 = 피격(적과 동일 규칙).
- **순간이동**: N웨이브마다 <추정 3> 이동. **다음 위치를 1턴 전 예고**(텔레그래프 없는 죽음 금지 — 공정성 불변식 유지 조건).

### A2. 위치 발원 공격 (기존 시스템 재사용 + 신규 3종)
| 공격 | 내용 | 재사용/신규 |
|---|---|---|
| 조준 사격 | 보스 셀 → 플레이어 방향 대각탄(vc) | 신규 `aimedFrom` |
| 방사탄 | 보스 주변 6방향 동시 burst | 신규 `radial` |
| 블링크 사격 | 순간이동 직후 착지점에서 방사탄 — "순간이동하며 쏜다" | 신규 `blink` |
| 직선 레이저 | 보스 **열**에서 발사 (기존 laser의 발원점만 보스로) | 재사용 |
| 광역 폭탄 | 보스 위치 기준 산개 투척 (기존 bombs 재사용) | 재사용 |

- 참고: 레이저(#24 추적 광선)와 폭탄(#19 3종)은 이미 존재 — 후반 보스에서만 나와서 초반엔 체감 불가.
  **각 보스 페이즈에 위치 발원 공격을 최소 1개씩 배치**해 초반부터 체감되게 재배선.
- 난이도: 예측 축이 "위에서 떨어짐" 하나에서 "보스 위치 기준"이 추가돼 자연 상승 → ④ 재측정 필수,
  fairness 확장(보스 이동 포함 "항상 회피 가능") 필수.

## B. 실시간 탄막 느낌 (요청 ③) — 방식 결정 필요

**전제 충돌**: 진짜 실시간은 이 게임의 4개 기둥과 충돌한다 —
턴제 결정론(같은 입력=같은 결과), 일일 도전 공정성(전국 동일 보드), undo, 헤드리스 자동 검증(봇 시뮬).

| 안 | 내용 | 기둥 영향 | 비용 |
|---|---|---|---|
| **B1 (추천)** | **연출 실시간**: 탄막이 셀 사이를 부드럽게 흘러내리는 보간 애니메이션(1945식 커튼 느낌) + **보스전 한정 입력 타이머**(<추정 3초> 내 미입력 = 자동 '대기') + 보스전 스폰 간격 2→1(밀도 상승) | 없음 — 타이머는 "대기 선택"과 동일해서 결정론·시뮬 무영향 | M |
| B2 | B1에서 타이머 제외(연출+밀도만) | 없음 | S~M |
| B3 | 진짜 실시간(탄이 벽시계로 이동) | **4기둥 전부 파괴** — 사실상 다른 게임 | L+ |

B1이면 "생각할 시간이 무한하지 않다 + 화면이 흐른다"로 실시간 체감을 만들면서 검증 체계가 살아남는다.

## 구현 순서 제안 (각 단계 ④/⑥ 재검증)
1. **A 보스 엔티티** (M~L): bossPos·텔레포트·신공격 3종·페이즈 재배선 + fairness 확장 + balance-sim 보스 재측정
2. **B1 연출** (M): 탄막 보간 애니 + 보스전 밀도 + 입력 타이머(보스전 한정, 설정으로 끄기 가능)

## 사람 결정
1. B안 선택: **B1(추천)** / B2 / B3
2. 입력 타이머 기본값 <추정 3초> — 및 보스전 한정인지 전 모드인지
3. 보스 순간이동 예고 방식: 착지점 표시(추천) vs 예고 없음(더 어렵지만 공정성 위반 소지)
4. 착수 순서: A→B1(추천) vs 동시
