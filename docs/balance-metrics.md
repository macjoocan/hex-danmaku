# 게임성 성공 지표 (초안 — 사람 확정 대기)

측정 기준: `tools/balance-sim.mjs` — 2-ply 스마트 회피 + 목표 추구 봇, 시드 고정 몬테카를로.
**봇은 스킬(undo/bomb/freeze) 미사용** — 상급 무스킬 플레이어 근사. 사람 평균은 이보다 낮고,
스킬 사용 시 이보다 높다. 지표는 "봇 기준"으로 정의한다(재현 가능한 유일한 기준).

## 목표 지표

| 지표 | 목표 | 근거 |
|---|---|---|
| 티어1 (#1–8) 봇 클리어율 | 스테이지당 ≥ 70%, 평균 ≥ 85% | 온보딩 구간 — 토스 유입 일반인 좌절 방지 (로드맵 진단 ④) |
| 티어2 (#9–16) 봇 클리어율 | 스테이지당 30~95%, 평균 55~85% | 긴장 구간 — 전멸도 무긴장도 금지 |
| 티어3 (#17–24) 봇 클리어율 | 스테이지당 20~90%, 평균 40~75% | 도전 구간 |
| 난이도 곡선 | 티어 평균이 단조 감소 (T1 > T2 > T3) | 뒤로 갈수록 어려워야 함 |
| 급사 금지 | 어떤 스테이지도 봇 클리어율 < 10% 불가 (스킬 체크 의도 스테이지는 명시 후 예외) | 벽 느낌 방지 |
| 무긴장 경계 | 티어2+ 비보스 스테이지 100%는 검토 대상 | 채움 스테이지 방지 |
| 클리어 턴 | normal ≤ 35 · collect ≤ 45 · boss ≤ 70 | 세션 길이(토스 미니앱 짧은 세션) |
| 공정성 | "항상 회피 가능" 불변식 유지 | fairness.test (기존, 유지) |

## 미측정 축 (한계 명시)
- **스킬 픽률/의존도**: 봇이 스킬을 안 써서 측정 불가. 스킬 사용 봇 추가 또는 사람 플레이 로그 필요 — 미결.
- **재미 자체**: 클리어율은 난이도 프록시일 뿐. 최종 판단은 사람 플레이.
